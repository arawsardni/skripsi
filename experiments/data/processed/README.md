# data/processed

Hasil praproses dari `data/raw/`. Isi folder ini di-gitignore — harus bisa dibangkitkan
ulang kapan saja dengan menjalankan skrip praproses di `src/`, bukan disimpan manual.

Kalau ada langkah praproses yang tidak deterministik (mis. random split), catat seed-nya
di `configs/`, bukan di sini.
